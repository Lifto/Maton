# Backlog

This file holds design ideas and possible future work for Maton that are worth
remembering but are not current commitments.

Backlog entries are not promises. They are project memory: useful pressure,
open questions, and feature-shaped thoughts that should be available when
working on Maton again.

## Dailies / Activity Logs

Idea: Maton may need "dailies" where activities are logged.

This would give each maton a chronological activity surface: what it did, what
it noticed, what it changed, what failed, and what should be reviewed later.

The shape might be a daily Markdown log, a dispatch journal, or another
human-readable activity record that fits Maton's git-native memory model.

Not currently committed.
